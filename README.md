
# 로또 조합기 — 겹침 없는 5줄 배치

5줄이 서로 번호를 공유하지 않도록 배치해 주는 웹 도구입니다.
1회부터 1241회까지의 실제 당첨번호가 내장되어 있고, 설치 없이 브라우저에서 바로 동작합니다.

## 이 도구가 하는 일

5줄을 살 때 번호가 겹치면, 적중이 여러 줄에 1개씩 흩어져 전부 2개짜리로 끝나기 쉽습니다.
겹침을 없애면 같은 적중이 한 줄에 모일 여지가 생깁니다. 등수는 한 줄 안에서 결정되므로
이것이 실제 차이를 만듭니다.

실제 1241회차 데이터로 8,000주를 시뮬레이션한 결과입니다.

| 배치 | 줄당 평균 적중 | 5등 이상 나온 주 | 4등 이상 나온 주 |
|---|---|---|---|
| 겹침 0 | 0.801 | **12.20%** | 0.78% |
| 겹침 허용 | 0.799 | 11.00% | 0.65% |

차이 +1.20%p, z = +2.37 (통계적으로 유의미)

줄당 평균 적중은 양쪽 모두 0.80으로 같습니다. 확률이 올라간 것이 아니라
배치가 등수에 유리하게 바뀐 것입니다.

## 이 도구가 하지 않는 일

당첨 확률은 높이지 못합니다. 아래 방식들은 같은 데이터로 검증했으나
모두 무작위와 구분되지 않았습니다 (|z| < 2).

| 검증한 방식 | 결과 |
|---|---|
| 번호 풀 좁히기 (8~30개) | 3개 이상 적중률 변화 없음 |
| 통계 필터 유무 및 조합 | 5등 확률 차이 없음 |
| 신경망(MLP) 예측 | 시드에 따라 0.767~0.893 출렁, 재현 안 됨 |
| 마르코프 체인 | z = -2.01, 오히려 무작위보다 낮음 |
| 빈도(HOT) / 콜드(COLD) / 이동평균 | 무작위 수준 |

로또는 독립시행이고, 한 줄의 기대 적중은 언제나 0.8개입니다.
GitHub의 다른 로또 예측 프로젝트들도 대부분 README에 같은 결론을 적어 두고 있습니다.

## 쓰는 법

`index.html` 파일 하나가 전부입니다. 브라우저로 열거나 GitHub Pages로 배포하세요.

1. **조합 만들기** — 5줄이 생성되고 자동 저장됩니다
2. **회차 추가** — 추첨 결과와 받은 당첨금을 입력하면 직전 조합이 자동 채점됩니다
3. **누적 성적** — 줄당 평균 적중, 5등 이상 비율, 지출 대비 수지가 쌓입니다

기록은 브라우저에 저장되며, JSON으로 내보내고 불러올 수 있습니다.

### GitHub Pages 배포

저장소에 `index.html`을 올린 뒤 Settings → Pages → Source를 `main` 브랜치 루트로 지정하면
`https://<사용자명>.github.io/<저장소명>/` 에서 열립니다.

## 적용된 조합 필터

합계 100~175 · 홀짝 2:4~4:2 · 고저 2:4~4:2 · 소수 1~3개 ·
같은 끝수 3개 이상 금지 · 3연속 번호 금지 · 32 이상 최소 1개

이월수 필터(직전 회차 번호 1~2개 포함)는 제외했습니다.
실제 당첨조합의 40.8%(1,239회 중 505회)를 탈락시키면서 5등 확률에는 이득이 없었습니다.

위 필터들도 5등 확률을 높이지는 않습니다. 조합의 모양을 고르게 유지하는 역할만 합니다.

## 참고

로또 환급률은 약 50%입니다. 넣은 돈의 절반이 평균적으로 돌아옵니다.
줄 수를 늘리면 당첨 확률도 지출도 같은 비율로 늘어납니다.
쓸 금액을 먼저 정하고 그 안에서 즐기시길 권합니다.
