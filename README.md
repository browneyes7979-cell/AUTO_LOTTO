# 로또 번호 뽑기 — 5줄이 안 겹치게

5줄을 살 때 줄끼리 같은 번호가 들어가지 않도록 짜 주는 웹 도구입니다.
설치 없이 브라우저에서 바로 동작합니다.

**[사이트 열기](https://browneyes7979-cell.github.io/AUTO_LOTTO/)**

## 무엇을 하나

5줄에 같은 번호가 들어 있으면, 그 번호가 맞을 때 여러 줄에 1개씩 나눠 들어갑니다.
결과적으로 전부 1~2개짜리로 끝나기 쉽습니다.
겹치지 않게 짜면 같은 적중이 한 줄에 모일 여지가 생기고, 등수는 줄 하나 안에서
정해지므로 5등(3개 적중)이 나올 가능성이 조금 올라갑니다.

실제 당첨번호 1,241회차로 8,000주를 시뮬레이션한 결과입니다.

| 5줄 사는 방식 | 줄당 평균 적중 | 5등 이상 나온 주 | 4등 이상 |
|---|---|---|---|
| 겹치지 않게 | 0.801 | **12.20%** | 0.78% |
| 그냥 뽑기 | 0.799 | 11.00% | 0.65% |

차이 +1.20%p, z = +2.37 (통계적으로 유의미)

줄당 평균 적중은 양쪽 모두 0.80으로 같습니다. 확률이 올라간 것이 아니라
배치가 등수에 유리하게 바뀐 것입니다.

## 무엇을 하지 않나

당첨 확률은 높이지 못합니다. 아래 방식들을 같은 데이터로 검증했으나
모두 무작위와 구분되지 않았습니다 (|z| < 2).

| 검증한 방식 | 결과 |
|---|---|
| 번호 풀 좁히기 (8~30개) | 3개 이상 적중률 변화 없음 |
| 통계 필터 유무 및 조합 | 5등 확률 차이 없음 |
| 신경망(MLP) 예측 | 시드에 따라 0.767~0.893 출렁, 재현 안 됨 |
| 마르코프 체인 | z = -2.01, 오히려 무작위보다 낮음 |
| 빈도(HOT) / 콜드(COLD) / 이동평균 | 무작위 수준 |

로또는 매 회차가 독립적이고, 한 줄의 기대 적중은 언제나 0.8개입니다.

## 파일 구성

| 파일 | 용도 |
|---|---|
| `index.html` | 방문자용. 번호 생성만 |
| `admin.html` | 운영자용. 회차 입력, 성적 기록, 갱신 코드 생성 |
| `data.js` | 1회부터 최신 회차까지의 당첨번호 |

## 회차 갱신 방법

방문자에게 최신 회차를 반영하려면 주 1회 아래를 반복합니다.

1. `admin.html`을 열고 당첨번호를 입력해 저장합니다
2. 맨 아래 **갱신 코드 만들기** → **복사**
3. GitHub에서 `data.js`를 열고 연필 아이콘 클릭
4. 기존 내용을 전부 지우고 붙여넣은 뒤 Commit changes

`admin.html`의 기록은 해당 브라우저에만 저장됩니다. 백업 내보내기로 JSON 파일을
받아 두면 다른 기기에서 불러올 수 있습니다.

## 적용된 조합 조건

합계 100~175 · 홀짝 2:4~4:2 · 고저 2:4~4:2 · 소수 1~3개 ·
같은 끝수 3개 이상 금지 · 3연속 번호 금지 · 32 이상 최소 1개

이 조건들도 확률을 높이지는 않습니다. 조합의 모양을 고르게 유지할 뿐입니다.
32 이상을 챙기는 것은 생일로 자주 고르는 구간을 피해, 당첨 시 나눠 가질 인원을
줄이려는 목적입니다.

이월수 조건(직전 회차 번호 1~2개 포함)은 제외했습니다. 실제 당첨조합의
40.8%(1,239회 중 505회)를 탈락시키면서 5등 확률에는 이득이 없었습니다.

## 참고

로또 환급률은 약 50%입니다. 넣은 돈의 절반이 평균적으로 돌아옵니다.
줄 수를 늘리면 당첨 확률도 지출도 같은 비율로 늘어납니다.
쓸 금액을 먼저 정하고 그 안에서 즐기시길 권합니다.
